# Инженерный калькулятор (NumPy)

Консольный калькулятор на Python с использованием библиотеки **NumPy** для математических вычислений. Включает валидацию ввода и защиту от деления на ноль.

## 🚀 Функционал
* Сложение, вычитание, умножение и деление
* Возведение в степень (`**`)
* Квадратный корень (`√`)

## 🛠 Установка и запуск

1. Установите библиотеку **NumPy**:
   ```bash
   pip install numpy
   ```
2. Запустите программу:
   ```bash
   python calculator.py
   ```
